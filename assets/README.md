# Assets

The default robot is generated procedurally at runtime (`src/eve/character/`), and icons
are drawn with QPainter (`src/eve/desktop/icons.py`), so this folder is intentionally
empty of binaries.

Put future, properly licensed assets here (e.g. a replacement character model for
`CharacterConfig.model_path`, see docs/rendering.md). Record the source and license of
every file you add in this README.
